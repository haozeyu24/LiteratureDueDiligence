# Abstract Review Rule

## Purpose

Define how abstract reviewers decide whether candidate papers belong in a
subsection-specific literature set.

## Allowed Decisions

- `include_primary`
- `include_context`
- `exclude_off_scope`
- `exclude_wrong_level`
- `exclude_low_quality_or_blocked`
- `uncertain_full_text_needed`

## Required Reason

Each decision must include a one-sentence reason tied to the subsection scope.
