# Draft Validation Artifacts

This folder stores the lightweight search trace and instruction-compliance checks for the initial review draft.

- `00_search/`: lightweight scholarly anchor search used before drafting.
- `01_checks/`: validation reports confirming that the draft followed citation, subsection, access-label, and provenance instructions.

This stage validates the draft only. It should not create formal PubMed retrieval artifacts, paper metadata sets, semantic-review batches, full-text corpora, or rewritten review sections.
