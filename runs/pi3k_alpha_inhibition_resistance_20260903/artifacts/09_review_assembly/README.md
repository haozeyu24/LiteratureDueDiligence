# Review Assembly Artifacts

This stage assembles normalized rewritten subsections into a single review draft. It does not add new scientific claims and does not perform claim-level verification.

- `01_inputs/`: assembly manifest.
- `02_sections/`: one assembled subsection file per normalized subsection.
- `03_verification/`: deterministic assembly checks.
- `04_outputs/`: compact assembly summary.
- `drafts/assembled_review.md`: assembled review draft for the next stage.
